# Inflection Intelligence v1

## Objective
Track whether a security is before, within, or after a repricing phase using independent inflection dimensions rather than a single composite label.

## Dimensions
The marketplace classifier records assessments for:
- Fundamental
- Earnings and margin
- Capital structure
- Industry
- Peer
- Macro
- Management expectations
- Estimate revisions
- Market recognition
- Technical
- Catalyst
- Position lifecycle

Each dimension stores stage, direction, confidence, velocity, contradictory evidence, required confirmation, and invalidation context.

## Synchronization Profile
A dedicated synchronization profile summarizes:
- Improving vs deteriorating dimension counts
- Agreement strength
- Contradictions
- Lead-lag relationships
- Recognition gap
- Timing opportunity label

This profile supports timing interpretation without changing base ranking behavior.

## Point-in-Time Safety
All assessments are anchored to observation time and available-at timestamps from upstream opportunity data.

## Current Integration
Inflection intelligence is attached to marketplace candidate classifications and remains explainability-first.
